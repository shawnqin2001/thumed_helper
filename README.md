# A login helper tool for THU Med computational cluster

## Usage

Run `thumed_helper` to open full-screen terminal UI.

- `↑`/`↓` or `j`/`k`: select action
- `Enter`: run action
- `q` or `Esc`: quit

This application uses TUI only; subcommand CLI has been removed.
